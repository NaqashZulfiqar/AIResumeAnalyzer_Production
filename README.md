# 🤖 AI Resume Analyzer

An AI-powered resume analysis application built with Python and LLM integration. The application analyzes resume content and provides structured insights through an interactive web interface.

## 📌 Project Overview

AI Resume Analyzer is designed to help analyze resume content using Artificial Intelligence and Natural Language Processing techniques.

The project processes resume information and provides insights that can assist with understanding candidate profiles and resume content.

The application includes a user-friendly interface built with Gradio and follows a modular Python project structure.
